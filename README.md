## Featured work

### 🏠 Homelab

My homelab is where I practice Linux administration, containerization, networking, storage planning, and troubleshooting. It includes:

- Docker-based Plex and Immich deployments
- Private remote administration through Tailscale
- Separate always-on and on-demand workloads
- Reused hardware selected for each workload
- Sanitized configuration and network documentation

The public documentation is being prepared in my **homelab** repository.

### 🤖 Local-first AI assistant

I'm developing and testing a personal-assistant workflow around **Hermes** and locally hosted open-weight models. The project combines:

- Local inference through Ollama
- Model comparisons for speed, context length, vision, and tool use
- Web, terminal, memory, and automation workflows
- A repeatable test suite for agent reliability
- Linux and Discord integration experiments

My current hardware lets me evaluate quantized and mixture-of-experts models without depending entirely on cloud inference.

### 🎬 Raspberry Pi NAS proof of concept
